# Produit

`max_games` : collection de petits jeux vidéo web pour un enfant (Max), créés avec un parent.
Dépôt public `sleroy/max_games`, publié sur GitHub Pages : https://sleroy.github.io/max_games/

- 1 jeu = 1 dossier dans `games/` ; la page d'accueil `index.html` les liste.
- Jeu principal : `games/peche_game/` (« L'étang du Bois Neuf », pêche 3D three.js, ~8 000 lignes).
- Autres : morpion (`jeu1`), Minecraft JS (3 variantes), Slime Adventure, page de démo.
- Interface et commentaires en français ; public enfant : textes simples, jeux tactiles et clavier.
- Idées et suivi du jeu de pêche : `idées.md` (ignoré par git, ne pas modifier sans demande).
